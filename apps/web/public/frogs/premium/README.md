Premium frog art goes here. Filenames must match the `image` paths in
`apps/web/src/characters.ts`:

  punk.png      → id "encore"     (Sid Vicious Toad)
  rockstar.png  → id "headliner"  (Ribbit Plant)

Same treatment as the free frogs in `../`: transparent PNG, frog facing the
viewer, roughly 512px tall. Until a file lands the card falls back to a
silhouette, so the picker never shows a broken image.
